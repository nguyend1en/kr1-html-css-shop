# ShopProject — учебный интернет-магазин

Многостраничный HTML/CSS-сайт интернет-магазина электроники, товаров для дома и аксессуаров. Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина: главная страница, каталог, страница товара, страница заявки и страница контактов. Проект выполнен без CSS-фреймворков, JavaScript используется минимально — для модального окна и сообщения об отправке формы.

- HTML5 (семантическая разметка, `<dialog>`, `<details>`, формы, таблицы);

## Обязательные страницы

| Страница | Содержание |
| --- | --- |
| `index.html` | hero-блок, преимущества, популярные товары, порядок заказа, модальное окно заявки |
| `catalog.html` | фильтры по категории, цене и наличию, 8 карточек товаров, модальное окно заявки |

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `section` — универсальный раздел страницы;
- `advantages` — преимущества;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `product-detail` — подробная информация о товаре;
- `data-table` — таблицы характеристик и сравнения;
- `review-card` — отзыв покупателя;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `order-steps` — шаги оформления заказа;
- `faq` — частые вопросы;
- `contact-list` — контактная информация;
- `button` — кнопка;
- `success-message` — сообщение об успешной отправке;
- `site-footer` — подвал сайта.

Примеры:

- элемент: `product-card__price`, `site-nav__link`, `order-form__input`, `faq__question`;
- модификатор блока: `product-card--discount`, `product-card--new`, `product-card--hit`, `product-card--unavailable`, `button--primary`, `button--secondary`;
- модификатор элемента: `site-nav__link--active`, `product-card__badge--new`, `order-form__field--checkbox`, `product-detail__status--available`.

## Самостоятельные доработки

1. **Расширенный каталог** — 8 товаров в трёх категориях, у каждой карточки есть категория; фильтры по категории, цене и наличию; счётчик найденных товаров.
2. **Варианты карточек через БЭМ-модификаторы** — «Скидка» (со старой ценой), «Хит», «Новинка», «Нет в наличии» (кнопка заказа отключена).
3. **Подробная страница товара** — список преимуществ, статус наличия, таблица характеристик, таблица сравнения, отзывы покупателей, блок похожих товаров; кнопка «Заказать» открывает модальное окно с выбранным товаром.
4. **Главная страница** — преимущества в виде карточек на Grid, блок «Как сделать заказ», две кнопки действия в hero.
5. **Страница заявки** — выбор товара, отметки обязательных полей, подсказка к телефону через `aria-describedby`, кнопка очистки формы, блок «Что будет дальше».
6. **Страница контактов** — адрес, режим работы, кликабельные телефон и e-mail, FAQ на `<details>/<summary>` без JavaScript.
7. **Доступность** — ссылка «Перейти к основному содержимому», видимый фокус `:focus-visible`, `aria-current` в меню, `aria-labelledby` у разделов, подписи у всех полей, учёт `prefers-reduced-motion`.
8. **Состояния интерфейса** — тень карточки при наведении, `:focus-within`, `:active` у кнопок, отключённые кнопки, подсветка некорректных полей.
9. **Позиционирование** — sticky-шапка и sticky-фильтры, фиксированная кнопка «Наверх», бейджи поверх изображения через `absolute` и `z-index`.

## Как проверить

1. Открыть `index.html`: проверить меню, якорные ссылки «Преимущества» и «Популярные товары», карточки с бейджами.
2. Нажать «Заказать» в любой карточке — откроется модальное окно; отправить пустую форму — браузер покажет ошибки; заполнить форму и отправить — появится сообщение об успешной отправке.
3. Открыть `catalog.html`: проверить хлебные крошки, sticky-фильтры, 8 карточек, отключённую кнопку у товара «Нет в наличии».
4. Открыть `product.html`: проверить таблицы, отзывы и кнопку «Заказать».
5. Открыть `order.html` и `contacts.html`: проверить форму и раскрытие вопросов FAQ.
6. Нажать Tab сразу после загрузки страницы — появится ссылка «Перейти к основному содержимому».
