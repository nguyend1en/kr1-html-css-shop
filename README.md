# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина или каталога услуг.

## Структура проекта

```text
kr1-html-css-shop/
├── index.html      — главная страница
├── catalog.html    — каталог товаров
├── product.html    — карточка товара
├── order.html      — форма заявки
├── contacts.html   — контакты
├── css/
│   └── style.css   — файл стилей
├── js/
│   └── main.js     — открытие и закрытие модального окна, сообщение об отправке формы
├── images/         — изображение товара (product.png)
├── .gitignore      — список файлов, исключённых из Git
└── README.md       — описание проекта
```

## Используемые технологии

- HTML;
- CSS (переменные, Flexbox, Grid, позиционирование);
- БЭМ-именование классов;
- JavaScript (минимально, для модального окна);
- Git;
- GitHub.

## Постановка контрольной работы №1

Тема контрольной работы №1: «HTML и CSS: разработка многостраничного сайта».

В рамках контрольной работы необходимо разработать многостраничный HTML/CSS-сайт интернет-магазина или каталога услуг.

Проект должен включать:

- главную страницу;
- страницу каталога;
- страницу карточки товара или услуги;
- страницу оформления заявки;
- страницу контактов;
- семантическую HTML-разметку;
- внешний CSS-файл;
- базовую навигацию;
- оформление основных блоков страницы.

## Обязательные страницы

| Страница | Содержание |
| --- | --- |
| `index.html` | hero-блок, преимущества, популярные товары, модальное окно заявки |
| `catalog.html` | карточки товаров, статический блок фильтров, модальное окно заявки |
| `product.html` | изображение, описание, цена, кнопка заявки, таблица сравнения товаров, карточки товаров |
| `order.html` | форма оформления заявки |
| `contacts.html` | контактная информация и ссылка на форму заявки |

## Реализованные элементы интерфейса

- кнопки заказа в карточках товаров;
- модальное окно с формой заявки;
- поля формы: имя, e-mail, телефон, дата, тема, комментарий, согласие;
- базовая HTML-валидация;
- базовая JS-обработка формы;
- сообщение об успешной отправке.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню, групп кнопок и внутренней структуры карточек товаров;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров (`grid-template-areas`).

## Самостоятельные доработки

- бейдж «Скидка» на карточке товара через БЭМ-модификатор (`product-card--discount`);
- таблица сравнения товаров на странице товара;
- sticky-блок фильтров в каталоге;
- фиксированная круглая кнопка «Наверх»;
- хлебные крошки на внутренних страницах;
- подсветка текущей страницы в меню (`site-nav__link--active`);
- видимый фокус (`:focus-visible`) и подсветка некорректных полей формы.
